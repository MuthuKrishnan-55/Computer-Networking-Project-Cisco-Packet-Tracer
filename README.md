# Computer Networking Project – Cisco Packet Tracer

## Overview

A comprehensive **computer network simulation project developed using Cisco Packet Tracer 8.2.1**, designed to demonstrate practical concepts of network design, configuration, communication, security, and network management.

The project simulates a real-world enterprise network consisting of **8 routers, 8 switches, 6 PCs, multiple network servers, an ASA 5506 firewall, Wireless LAN Controller, printer, and interconnected network segments**.

## Key Features

* Configured **8 routers and 8 switches** for network connectivity and communication.
* Integrated **6 PCs** into different sections of the network.
* Configured **DHCP** for automatic IP address allocation.
* Implemented **VLANs and Inter-VLAN Routing** for network segmentation.
* Configured **VTP** for VLAN management across switches.
* Simulated **DHCP, FTP, TFTP, Email, and SYSLOG servers**.
* Implemented an **ASA 5506 firewall** for network security.
* Configured **Wireless LAN Controller (WLC)** for wireless network management.
* Included **tunnel connections** for communication between different networks.
* Integrated a **network printer** as a peripheral device.
* Designed and visualized the complete network topology in Cisco Packet Tracer.
